## **📘 Клас: `Book`**

**Име:**  
 Book

**Отговорности:**

* Представлява една книга в системата

* Съхранява основна информация за книгата

* Предоставя метод за извеждане на информация в конзолата

**Данни (полета):**

* `private string title` – заглавие на книгата

* `private string author` – автор на книгата

* `private int year` – година на издаване

**Методи:**

* `Book(string title, string author, int year)` – конструктор за инициализация на данните

* `DisplayInfo()` – извежда информация за книгата

**Сътрудници (други класове):**

* Library (книгата се съхранява в библиотеката)

* Program (създава обекти от тип Book)

---

## **📚 Клас: `Library`**

**Име:**  
 Library

**Отговорности:**

* Управлява колекция от книги

* Добавя книги в библиотеката

* Показва всички книги, съхранени в колекцията

**Данни (полета):**

* `private List<Book> books` – списък с книги

**Методи:**

* `Library()` – конструктор, който инициализира списъка с книги

* `AddBook(Book book)` – добавя книга в колекцията

* `ShowAllBooks()` – извежда информация за всички книги

**Сътрудници (други класове):**

* Book (елементи в списъка)

* Program (използва методите на Library)

---

## **📚 Клас: `Reader`**

**Име:**  
 Reader

**Отговорности:**

* Представлява читател на библиотеката

* Съхранява информация за читателя

* Позволява извеждане на информация за читателя

**Данни (полета):**

* `private string name` – име на читателя

* `private int age` – възраст на читателя

**Методи:**

* `Reader(string name, int age)` – конструктор

* `DisplayInfo()` – извежда информация за читателя

**Сътрудници (други класове):**

* Program (създава и използва обекти от тип Reader)
