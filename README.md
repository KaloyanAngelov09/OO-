Library Console Application

Съдържание: 
OOP proekt.rar - Главната задача на C#
Книги ООП.md - Файл, който съдържа информация за класовете използвани в задачата
ООП Проект Калоян 10г.pptx - Презентация направена с цел представяне на задачата

📝 Кратко описание

Конзолно приложение на C#, което реализира опростена система за управление на библиотека, използвайки обектно-ориентиран подход.

⚙️ Какво прави проектът

Създава и съхранява книги

Управлява книги чрез колекция List<Book>

Позволява въвеждане на информация за читател от клавиатурата

Извежда информация в конзолата

🛠 Използвани технологии

Език: C#

Тип приложение: .NET Console Application

▶️ Как се стартира проектът

Проектът се отваря в Visual Studio

Стартира се като Console Application

Програмата се пуска с клавишна комбинация Ctrl + F5 или чрез бутона Start

Взаимодействието с приложението се извършва чрез конзолата (клавиатура)

Структура:  

  Book – информация за книга

  Library – колекция от книги

  Reader – читател
  
  Program – стартира приложението
