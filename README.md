# Кратко обяснение на проекта

Описание:

Конзолно приложение на C#, което реализира опростена система за управление на библиотека. Проектът е разработен с обектно-ориентиран подход и демонстрира основни ООП принципи.

Функционалности:

  Създаване и съхраняване на книги

  Управление на книги чрез List<Book>

  Въвеждане на информация за читател от клавиатурата

  Извеждане на информация в конзолата

Структура:  

  Book – информация за книга

  Library – колекция от книги

  Reader – читател
  
  Program – стартира приложението

ООП принципи:

  Капсулация (private полета)

  Разделение на отговорности
