# Кратко обяснение на проекта
Проектът представлява конзолно приложение на C#, което реализира опростена система за управление на библиотека. В приложението се използва обектно-ориентиран подход с ясно разделение на отговорностите между класовете. Създадени са класове за книга, библиотека и читател, като данните се капсулират чрез private полета. Библиотеката съхранява книги в колекция от тип List<Book>, а информацията за читателя се въвежда от клавиатурата. Проектът е структуриран четимо и е подходящ за демонстрация на основни принципи на обектно-ориентираното програмиране.
